# Tombola

A dual tombola (raffle drum) web application with a vintage circus aesthetic. Add slips to two separate drums and draw random winners with animated spinning drums.

## Features

- Two independent tombola drums
- Add and remove slips from each drum
- Animated drum spinning and slip ejection
- Tracks drawn slips and history
- Reset draws or clear everything
- Swedish UI with vintage burgundy/gold styling

## Tech Stack

- Next.js 16 with App Router
- React 19
- TypeScript
- Tailwind CSS 4

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000
